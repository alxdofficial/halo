Real-Time Sensor-Based Human Activity Recognition for eFitness and eHealth Platforms

Publication DOI: https://doi.org/10.3390/s24123891
Article: https://www.mdpi.com/1424-8220/24/12/3891
Dataset page: https://www.aidlab.com/datasets
Direct archive: https://aidlab-production-datasets.s3.eu-central-1.amazonaws.com/AIDLAB-HAR-DATASET_v3.zip

Verified for application planning on 2026-08-29. The complete 3.29 MB release contains 180 EDF
recordings and 130 annotation CSV files at 50 Hz. The released chest channels are acceleration in g
plus orientation quaternion; raw gyroscope is absent. The 130 annotated series contain 1,486 paired
repetition-marker onsets and offsets across 13 exercises, plus plank, running plank, and walking.
The release README states that SUBxx values are source codes rather than globally unique participant
identities. Its repetition-marker intervals are fiducial windows, not full repetition boundaries.
The application adapter exposes all 180 acceleration recordings, masks 4,512 invalid samples, keeps
the 1,486 marker windows explicitly typed as fiducials, and uses recording-scoped identities because
the release does not provide a defensible participant map.
